For each iteration, I manually adjusted the scale, rotation, and translation of each shape in Photoshop to explore different compositions. Every variation was an intentional, deliberate decision made by myself. When it comes to process drawing, I struggled a bit to change the variables because it was not as intuitive as drawing. It is undeniably much more efficient to automate the process, specifically using the random() function to generate many possibilities and choose from them. However, in order to get a better control over the result, more effort is required. What I took from this assignment is, there is a good and bad time to use random() function. If I have some visuals in mind, I should just do it the 'hard' way, which might actually be the 'easy' way. And at times, when chaos is necessary, then go ahead and randomize everything!
