I have no idea what to do for this week so I just went scrolling the publi apis and narrowed downt the scope to books. I want the api to include not only author and book name, but also a cover image so it's easy to make the sketch more visual. 
I found the Open Library which matches my need:
https://publicapis.lol/apis/open-library It also includes some interesting projects that use this api. The Virtual Shelf is a visualization created by two students at the UC Berkeley School of Information: https://www.ischool.berkeley.edu/projects/2009/virtual-shelf
I wanted to create something similar with one of my favorite novelist Agatha Christie.

It was very hard to get what I want because some of the books published in earlier years didn't come with covers. So I had to find ways to narrow the scope to get what I want. Some of Agatha's later's work was also not included in the search find since I tried to limit the final number that put on the shelf to 20-30. The popularity wasn't include in the information it returned, but it did provide edition number, which could be an indicator. The more popular the book is, the more times it got published.

I added a magnifying glass as cursor to pay respect to the greatest mystery novelist. If I had more time, I'd give the background and shelf a more vintage look. Maybe include a short description for each book, but the information is not included in the Open Library.
